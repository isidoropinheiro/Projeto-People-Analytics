# Projeto-People-Analytics
Estudo direcionado ao entendimento e à aplicação de conceitos de análise de indicadores voltados a People Analytics.
<br>


📕 TAREFAS
1. Criar bases de estudo contendo:
- Base 1 — Colaboradores: dados referentes aos colaboradores, contendo cargo, senioridade, salário, região, área e gestor;
- Base 2 — Desligamentos: dados referentes à data de admissão, data de desligamento e motivo do desligamento.
<br>


2. Analisar as bases e criar análises e indicadores aderentes a People Analytics, como, por exemplo:
- Turnover;
- Headcount;
- Absenteísmo;
- Análise de desligamentos.
<br>


3. Criar Dashboard com as análises realizadas e disponibilizar as respectivas conclusões.
<br>


🛠️ FERRAMENTAS
- Python
- SQL
- Power BI
